Earthshaker V1.0

Advisory screening for shortlisted data center sites. Ranks on regulatory risk, cost, and impact on neighbors.

Run —

This tool advises and does not decide. It screens a shortlist that upstream work produced; it does not find sites, generate profiles, or establish feasibility. Nothing here is evidence of grid capacity, zoning approval, or a utility commitment.

Priorities

Set by leadership. Weights are normalized to 100%, so moving one slider changes the others' share.

Narrowing

    Hard constraints are screened before scoring, so no weighting can rescue an excluded site or promote a held one. Only steps 3 and 4 move when you change the sliders.

    How the score is built

    Reported scores are pessimistic: an unknown factor contributes zero. Missing data can never improve a site's position. The ceiling shows where a site would land if every unknown resolved in its favor, and completeness is reported separately from suitability.
